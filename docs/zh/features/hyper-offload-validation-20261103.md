# HyperOffload 通用调优验证记录（2026-11-03）

基于 PR #14 的同源对照，通用自动策略三次稳定步时的几何均值为 **9.164121 秒**，固定 R28 为 **10.252589 秒**；配对耗时降低 **10.617%**。这不是相对“关闭卸载”的收益，也不代表优于所有手工固定策略。

## 对照和统计口径

- Qwen2.5-32B 前48层、seq4096、batch1、BF16、SGD lr0.01，双 NPU 910B3，整组固定使用2/3卡和NUMA4。
- 双方均启用 HyperOffload、原始格式卸载、搬运掩盖及 PR #14 缓存回收；初始配置均为前28层整层重计算。固定参考绕过调优观测和决策，自动模式使用生产 MeasuredOffloadSession。
- 激活预算2GiB、Host预算128GiB、allocator fraction0.95；完整训练配置、最终策略和证据摘要见随附JSON。
- 每次36步，13–36步逐步取双rank最大耗时，再取24步中位数；三组比值取几何均值。顺序A1、B1、B2、A2、A3、B3，六次全新启动，筛选不计入。
- R28/R31曾做独立筛选，差距约0.16%，仅用于固定参考配置选择；未声称人工全局最优。只有三组独立复测，不将连续训练步当作独立实验，也不声称统计显著。

## 调优成本和冻结

三次自动运行分别在第 11/12/11 步冻结，稳定阶段的调优计数保持不变，观测hook均移除。三次最终策略均为14个整层重计算加136个子区域重计算，共150个区域，清理周期1、raw。普通运行时内存压力回收继续执行。默认预算10步，本次实验显式使用12步上限。

| 配对 | 自动前12步 / 秒 | 直接固定实际最终策略 / 秒 | 额外秒数 | 额外比例 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 133.268820 | 118.912668 | 14.356152 | 12.073% |
| 2 | 134.259705 | 118.945013 | 15.314692 | 12.875% |
| 3 | 134.017422 | 120.184186 | 13.833236 | 11.510% |

严格成本包含session初始化及前12步完整墙钟；三次对照各自使用自动运行的实际最终策略，捕获/校准配置和训练长度相同。额外成本范围 13.833–15.315 秒（11.51%–12.88%）。不能将与初始R28的前12步差值称为调优开销。

共同的模型加载和分布式初始化在计时边界之前。本轮开启轨迹证据落盘，额外成本包含多候选带来的诊断记录；不等同于关闭诊断时的纯算法耗时。稳定阶段不再采集轨迹。

纯候选计算每rank累计取最大值为 55.88–56.59 ms；建计划累计为 2.460–2.488 秒。每次策略切换为 5.506–196.245 ms；切换不包含新结构整步轨迹采集的所有成本。各计时项存在嵌套，不相加。50ms搜索、2秒规划和10%前12步额外成本是报告参考值，稳定性能与硬性12步冻结分别验收。

本轮上述三项均超过对应参考值，完整数据如实保留；三次自动运行均满足12步冻结上限。

## 正确性、容量与压缩

- 当前硬件源码通过852项CPU测试及4项subtests、11项原生codec测试；六组双rank小模型各16步，含dropout、确认接受/回退、并行结构和真实codec路径。逐步loss、全部本地参数/梯度、输入梯度和RNG一致。构造的候选计时只用于覆盖控制分支，不计性能。
- 六次Qwen复测及三个实际最终策略对照：每步标量探针一致，全部最终本地参数和梯度摘要一致；这不是每一步全量梯度比较。
- 每次运行检查allocated、Host池和冻结状态；reserved和设备物理内存采样另存JSON。PR #14保留物理句柄，因此reserved下降不代表物理内存已归还系统。
- SplitZip位级无损压缩、选择性接口、raw回退、不可变codec配置及有界包缓冲实现均保留且通过资格验证。本轮自动候选仍只生成raw；自动压缩校准/选策的生产接线和当前Qwen上的压缩收益未验证。

## 泛化边界和已知限制

生产决策读取合法区域、实测成本、生命周期和容量，没有针对Qwen模型名称、层号或张量尺寸的特例。Qwen特定历史候选位于示例legacy_tuning.py，部署和手工扫描材料独立保存。当前性能结论仅适用于本轮Qwen配置，不能外推为跨模型性能保证。

当前初始传输校准存在敏感性：g18两次筛选的216MiB D2H中位耗时分别为15.962ms和38.098ms；相同初始计算图和设备余量下，整层替换的预计收益分别为+19.257ms和−47.084ms。对冻结输入交叉替换传输校准数据，收益门槛随之翻转，解释了为何生成150区域或108区域候选。硬件波动来源未查明；离线重算不是新的性能实验。有限候选和短warmup不能保证全局最优，后续应处理校准不确定性并重新做容量和完整训练步验证。
